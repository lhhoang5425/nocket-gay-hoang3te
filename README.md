## 📖 Hướng Dẫn Cài Đặt Vào Shadowrocket

### 🔹 Cách 1: Nạp vào mục "Cấu hình" (Khuyên dùng - Đơn giản nhất)
1. Mở ứng dụng **Shadowrocket** trên iPhone/iPad.
2. Chọn tab **Cấu hình (Config)** ở thanh điều hướng dưới cùng.
3. Nhấn vào **dấu `+`** ở góc trên cùng bên phải.
4. Dán đường link URL bên dưới vào ô nhập:
   ```text
   https://raw.githubusercontent.com/lhhoang5425/locket-gold-hoang3te/main/locket-gold-hoang3te.conf
   ```
5. Nhấn **Tải xuống (Download)**.
6. Nhấn vào file **`locket-gold-hoang3te.conf`** vừa tải về để hiện **dấu tích màu cam/xanh (Checkmark)**.
7. Vào **Cài đặt (Settings)** trên iPhone ➔ **Đã tải về hồ sơ** ➔ Cài đặt chứng chỉ Shadowrocket ➔ Vào **Cài đặt chung > Giới thiệu > Cài đặt tin cậy chứng nhận** ➔ Bật tin cậy đầy đủ cho chứng chỉ Shadowrocket.
8. Quay lại Shadowrocket, bật công tắc **Kết nối (VPN)** lên và tận hưởng!
